# 要件定義
オリプロで制作するアプリの要件定義を実施。

## サービスコンセプト 
**「積立投資」という選択をもっと身近に**  

近年、積立投資を始める人が増えてきていると話題になることが多いが、実際にはまだnisa利用者は3割にも満たず一般世間に浸透しているとは言い難い状況である。
周りに投資している人が少なく実際のイメージがわきにくい、そもそも日本ではまだ投資＝投機という考えが根強く漠然とした不安から興味を持っても始められない人は相当数いると考えられる。

こういった人々に対して、積立投資をすることでどのようなメリットがあってどういったリスクがあるのかを**正しく**理解してほしい。  
そのうえでライフプランニングに「投資」という選択肢があることを知ってもらいたい。

## 誰のどんな課題を解決するのか
今回のターゲットは、

- 投資を始めたいけど何をすればわからない人
- 投資に漠然とした不安を持っている人
- 年齢は20~30代の若年層

に絞る。年代を若年層に設定したのはnisaのような積立投資の商品は長期保有による運用を想定している（特別なスキルや知識に左右されず、万人での再現性が高いと言われている）ものが多いためである。

※ 個別株のような個人の知識や技量に大きく左右されるものは今回の対象にしない
