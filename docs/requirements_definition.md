# 要件定義
オリプロで作成するアプリの要件定義（機能要件・非機能要件）を行う。

## 作成アプリのターゲット
- 自部署3Dプリンターを使用するすべての利用者
（自部署内＋他部署社員。現時点では10人/月程度）

## 解決したい課題
### ① 自部署の人が自由に3Dプリンターを使用できず、業務上支障をきたすことがある
自部署で管理を行っている機械であり、最初は空いている時間帯のみ貸し出す形で運用を始めた。しかし他部署の利用が想定以上に増えてしまい3Dプリンターの利用がひっ迫してしまった。
現段階ではoutlookでの先着予約性となっているので、どんどん他部署の人に予約を入れられてしまい自部署内で不満が高まっている。

### ② メンテナンス管理を忘れてしまい機械が定期的に故障する  
使用している3Dプリンターは一定の稼働時間を過ぎると部品交換が必要であったり、月次点検もする必要がある。そのため稼働時間や前回点検日などを細やかに記録する必要があるのだが、業務が忙しくてほとんど記録されずに放置・壊れたら初めて取り換えるという状態が慢性化してしまっている。  
→ 事後保全になってしまい業務が停滞している＝解決の手立てが必要。

## 課題要因の深堀り
### ① 自部署の人が自由に3Dプリンターを使用できず、業務上支障をきたすことがある
- 利用者に優先順位がなく、予約の早い者勝ちになっている
- 予約の占有や仮押さえが一部見受けられる（先約主義が原因か？）
- 利用の需要と供給のバランスがあっていない  
（3Dプリンター1台で工場内のすべての従業員が使用できる状態→台数増やすべきでは？）

### ② メンテナンス管理を忘れてしまい機械が定期的に故障する
- 利用予約から都度稼働時間を算出してスプレッドシートに記載...→面倒！
- 業務が忙しく、メンテナンスのことを考える余裕がない

## 得られた要因に対する解決法
それぞれの要因から考えられる対策法を挙げていく。

### ① 自部署の人が自由に3Dプリンターを使用できず、業務上支障をきたすことがある
- 予約を承認制とする（自部署内メンバーを承認者とすれば優先して使用できる）
- 予約の利用制限を設けて一部ユーザの占有を防ぐ
- 3Dプリンターの台数を増やしてもらう ← 予算的に厳しいとの回答

### ② メンテナンス管理を忘れてしまい機械が定期的に故障する
- 予約時の情報から稼働時間を自動算出して交換の目安時期を知らせる
- 月次点検に関しても点検時期のお知らせ機能をつける

## 課題の解決方法
挙がった解決案をもとに、今回のアプリ開発では以下のようあ形での実装を目指す。
- 予約を承認制とする（自部署内メンバーを承認者とすれば優先して使用できる）
- 予約の利用制限を設けて一部ユーザの占有を防ぐ
- メンテナンス管理はアプリが自動で行う。管理者はアプリを開くだけでいつメンテナンスすべきかを分かるようにする
